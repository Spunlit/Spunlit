LLM-powered backends.

- **Networking:** Cisco labs in Packet Tracer (VLAN, ACL, port security, SSH, WPA2); CCNA: Switching, Routing, and Wireless Essentials
- **Monitoring:** Zabbix alerts and dashboards, Grafana
- **AI / backend:** RAG pipelines and LLM chatbots for clients, Python and FastAPI services
